📌 Description
Ce projet est une application e-commerce frontend développée avec React et TypeScript, connectée à un backend Django. L'application permet aux utilisateurs de parcourir des produits, gérer un panier, passer des commandes et plus encore.

🚀 Prérequis
Avant de commencer, assurez-vous d'avoir installé:
Node.js (v14 ou supérieur)
npm (v6 ou supérieur) ou yarn
Le backend Django doit être en cours d'exécution (voir le README du backend pour les instructions)

🔧 Installation
git clone https://github.com/TCHUINDJANG/Ecommerce_Frontend_React_App.git
cd [NOM_DU_REPERTOIRE_FRONTEND]

Installer les dépendances
npm install

Configurer les variables d'environnement
Créez un fichier .env à la racine du projet en vous basant sur le fichier .env.example

REACT_APP_API_URL=http://localhost:8000/api
REACT_APP_MEDIA_URL=http://localhost:8000/media


🏃 Lancer l'application
Pour démarrer l'application en mode développement:
npm run dev

L'application sera disponible à l'adresse: http://localhost:3000
